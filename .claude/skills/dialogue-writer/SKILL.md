# Сценарист диалогов

## Формат (`game/src/data/dialogues.js`)

```js
npc_id: {
  start: (g) => {                 // выбирает первый узел по состоянию мира
    if (g.at('quest', 'npc_id')) return 'intro';    // текущая цель квеста — поговорить с этим NPC
    if (g.state('quest') === 'ready') return 'done';
    if (g.can('side_q')) return 'offer';
    return 'hub';
  },
  nodes: {
    intro: {
      text: 'Реплика NPC.',       // строка или (g) => строка
      options: [
        { text: 'Ответ героя.', next: 'node2' },
        { text: 'Принять.', action: (g) => g.start('side_q') },     // без next — диалог закрывается
        { text: 'Только если флаг.', cond: (g) => g.flag('x'), next: 'secret' },
      ],
    },
  },
},
```

API `g`: `name`, `level`, `state(q)` (none/active/ready/done), `at(q, npc)`, `objIndex(q)`, `can(q)`, `start(q)`, `advance(q)`, `turnIn(q)`, `has/take/give(item, n)`, `flag/setFlag(f)`, `open('shop'|'craft'|'smith')`, `shards()`, `waystones()`, `openDome()`, `ending(c)`, `bossDead(id)`.

Порядок проверок в `start` важен: сначала «цель — поговорить», потом «готово к сдаче», потом новые предложения, потом «в процессе», в конце `hub`.

## Обязательное правило: герой без рода

Пол героя не задаётся, поэтому **никаких форм, выдающих род**, в репликах к герою и в ответах героя:

| Нельзя | Можно |
|---|---|
| «Ты пришёл / пришла» | «Ты здесь», «Наконец-то», «Глаза открыты — слава Жилам!» |
| «Ты готов?» | «Пора?», «Готово ли сердце?» |
| «Я справился» | «Сделано», «Я справлюсь» (будущее время без рода) |
| «Рад помочь» | «Всегда пожалуйста» |
| «Молодец, герой» | «Хорошая работа», «Это твоих рук дело» |

Безродовые обращения: «дитя», «Осколочник», «светлячок», по имени (`g.name`). Существительное-титул допустимо, но согласованные с ним прилагательные и глаголы прошедшего времени — нет.

## Как писать

- Узел — одна мысль, до ~350 знаков. Длинный рассказ — цепочка узлов с вопросами героя («Расскажите о Расколе.»).
- Ответы героя — короткие, активные, разные по тону (вопрос / согласие / сомнение).
- Каждый квестовый NPC имеет: `intro`/`offer` (зачем), `wait` (куда идти, с направлением по сторонам света), `done` (награда + новая деталь лора), `hub` (2–3 лор-вопроса + «Прощай.»).
- Ремарки — в скобках третьим лицом: «(Элиан отводит взгляд.)».
- Действие с последствием (финал, открытие Купола) — отдельная явная опция с пояснением в скобках.

## Реплики боссов

`BOSS_BARKS[type] = { aggro, half, death }` — до 120 знаков, в характере существа; `half` звучит на 50% здоровья вместе со второй фазой.

## Новый NPC — шаги

1. `src/data/npcs.js`: имя, титул, координаты (`x`, `z`, `yaw`), внешность (`model`: skin, cloth, cloth2, hair, robe/hood/hat/helmet/beard/horns/fur, weapon, staffGlow, scale), роли (`shop`, `craft`, `smith`).
2. `src/data/dialogues.js`: блок с `start` и `nodes`.
3. Если NPC торгует — ассортимент в `STOCK` (`src/systems/shop.js`).
4. Проверка: `npm run dev`, подойти и нажать E; для квестов — `node tools/quest-test.mjs`.
