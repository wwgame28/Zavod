# Строитель мира

## Устройство карты

- Остров ~1600×1600 м, координаты `x` — восток, `z` — юг (**север = −z**), центр (0, 0). Высота берётся из рельефа автоматически.
- Регионы — мягкий Вороной по центрам из `src/data/regions.js`; у каждого своя функция высоты (`Terrain.regionHeight`), палитра, туман, погода, музыка.
- Карта с подписями: `game/docs/map.jpg` (пересоздать: `node tools/export-map.mjs` при запущенном `npm run dev`).

| Вересковая Долина | (0, 250) | 1–5 | пологие холмы |
| Шепчущий Лес | (−420, 210) | 4–9 | холмы, густой лес |

## Что где описывается (`game/src/data/locations.js`)

| Массив | Что | Поля |
|---|---|---|
| `WAYSTONES` | путевые камни (телепорт, точка возрождения) | id, name, x, z, region, insideDome? |
| `ROADS` | дороги-ломаные: рельеф окрашивается | `[[x,z], …]` |
| `FLATTEN` | выравнивание рельефа под деревни, лагеря, арены | x, z, r |
| `STRUCTURES` | постройки | type, x, z, rot, параметры билдера |
| `CAMPS` | лагеря врагов | id, x, z, r, levels [a,b], types[], count, insideDome? |
| `BOSSES` | арены хранителей | id, type, x, z, level, arena, shard? |
| `TABLETS`, `CHESTS`, `QUEST_OBJECTS` | скрижали, сундуки, квестовые объекты | id, x, z, … |
| `LAVA` | лава (урон) | x, z, r |

Узлы сбора трав расставляются процедурно по `GATHER` (`src/data/items.js`), декорации — по `RULES` (`src/world/props.js`) с учётом региона, высоты, уклона, дорог и зон исключения вокруг построек.

## Новая постройка

Билдеры — `BUILD` в `src/world/structures.js`. Каждый возвращает геометрию в локальных координатах:

```js
my_building({ color = 0xc9b08a }) {
  const solid = [G.box(6, 3, 5, color, { y: 1.5 }), ...];      // матовые части (сливаются в 1 меш)
  const glow = [G.box(0.9, 0.8, 0.1, 0xffc46a, { y: 2, z: 2.5 })]; // светящиеся (окна, руны)
  return { solid, glow, col: [{ b: [0, 0, 3.2, 2.7, 0] }] };     // коллайдеры: {c:[x,z,r]} или {b:[x,z,hw,hd,rot]}
},
```
Опционально: `float` (парящие кристаллы), `rotor` (вращение: мельница, луч маяка), `fire` (точечный свет и огонь), `light`, `heart`. Добавь радиус исключения декораций в таблицу `R` в `World._structures`.

Стиль: low-poly, плоское затенение, 1 основной цвет + 1 тёмный акцент, светятся только «магические» детали. Размеры — человек ≈ 1,8 м, дверь ≈ 2 м, дом ≈ 6×5 м.

## Правила расстановки

- Деревня/лагерь/арена → добавь `FLATTEN` с радиусом на 20–30% больше самой постройки.
- Путевой камень — у каждого хаба региона и на развилках дорог; между соседними камнями ≤ 350 м.
- Лагерь врагов — в 60–150 м от дороги, не ближе 40 м к NPC; уровни лагеря — внутри уровней региона.
- Арена босса — плоская площадка `arena` 24–38 м, вход видно с дороги; рядом скрижаль или сундук.
- Внутри Купола — поле `insideDome: true` (появится после открытия Купола).
- Не ставь точки дальше ~700 м от центра: дальше начинается берег и океан.

## Проверка

```bash
cd game && npm run dev &                                   # http://localhost:5173
node tools/shot.mjs "http://localhost:5173/" tools/out/x.png   # титульный экран
node tools/smoke-test.mjs                                  # обход регионов со скриншотами в tools/out/13-*.png
node tools/export-map.mjs                                  # обновить docs/map.jpg
```
Для точечного осмотра в браузере: `__G.player.pos.set(x, __G.terrain.heightAt(x, z), z)` в консоли.
