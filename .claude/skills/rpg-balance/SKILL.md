# Балансировщик

## Где числа

| Что | Где |
|---|---|
| Все константы и кривые (`xpCurve`, `enemyXp`, `masteryXp`, броня, кап сопротивлений, шансы лута) | `game/src/config.js` |
| Производные статы игрока, множитель заклинаний, масштаб врагов | `game/src/systems/stats.js` |
| Формула урона, криты, броня/сопротивления, статусы | `game/src/systems/combat.js` |
| Навыки: база по рангам `vals(r)`, мана, перезарядка | `game/src/data/skills.js` |
| Враги и боссы: база на 1-м уровне, атаки, способности | `game/src/data/enemies.js` |
| Предметы: базы, аффиксы, уникальные, рецепты, бонусы Осколков | `game/src/data/items.js` |
| Генерация, цены, разбор, стоимость улучшения | `game/src/systems/items.js` |
| Описание всех формул для людей | `game/docs/MECHANICS.md` |

## Инструмент

```bash
cd game && node tools/balance.mjs        # таблицы в консоль
cd game && node tools/balance.mjs --md   # в Markdown — вставить в docs/MECHANICS.md
```

Показывает опыт по уровням и сколько убийств нужно, сумму опыта за квесты, HP/урон/броню врагов и боссов.

## Целевые ориентиры

| Метрика | Цель |
|---|---|
| Убийств обычных врагов своего уровня до следующего уровня | 8 → 21 (растёт медленно) |
| Время убийства обычного врага своего уровня | 2–5 с (2–4 попадания основным заклинанием) |
| Время боя с хранителем региона | 20–45 с при экипировке своего уровня |
| Сколько ударов обычного врага выдерживает герой | 12–20 |
| Опыт за квесты + боссов | ~70% пути до уровня финального босса (27); остальное — бои |
| Доля базовой атаки в уроне | ≤ 40% (заклинания должны быть сильнее) |

Быстрая оценка урона героя: `База × (1 + 0,075·(Ур−1)) × (1 + СМ/100) × (1 + 0,03·Мастерство) × (1 + %школы)`. СМ ≈ `2·Инт + 3·Ур` при обычной экипировке.

## Ручки настройки (от грубой к тонкой)

1. **Сложность целиком:** `DIFF` в `src/game.js` (множитель получаемого урона).
2. **Темп уровней:** `xpCurve`, `enemyXp` в `CONFIG.PROGRESSION`.
3. **Рост врагов:** `enemyHpPerLevel`, `enemyDmgPerLevel`, `enemyArmorPerLevel`.
4. **Рост героя:** `playerSkillPerLevel`, коэффициенты в `computeStats`.
5. **Отдельный враг/навык:** его поля в `data/enemies.js` / `data/skills.js`.
6. **Лут:** `rarityWeights`, `itemChance`, множители редкости `RARITY` и `v` аффиксов.

Меняй одну ручку за раз и пересчитывай таблицы.

## Добавление навыка

```js
new_skill: {
  school: 'fire', tier: 2, type: 'active', name: 'Название', icon: 'wave', max: 5, mana: 20, cd: 6,
  ground: true, range: 28,            // для навыков по точке
  vals: (r) => ({ dmg: lin(40, 12)(r), radius: 4 }),
  desc: (v) => `… ${v.dmg} урона …`,  // числа подставляются с учётом силы магии
},
```
Добавь id в `SKILL_ORDER[school]`, реализацию — в `switch` метода `Spells.cast` (`src/systems/spells.js`), иконку — в `S` (`src/ui/dom.js`). Пассивка вместо реализации задаёт `stats: (r) => ({ stat: value })`, которые читает `computeStats`.

Правило силы: урон за ману у активного навыка круга N ≈ 2–2,5 × (N); у навыка с перезарядкой > 10 с — суммарный урон ≥ 4× урона основного заклинания.

## Добавление врага

Базовые статы — на 1-м уровне; уровень задаёт лагерь (`CAMPS.levels`). Сравни с соседями по региону через `balance.mjs`. Дальникам — `keepDistance`, летающим — `flying`, элитным способностям — `abilities`.

## Проверка

- `node tools/balance.mjs` — таблицы.
- `node tools/smoke-test.mjs` — бой у кратера должен дать хотя бы одно убийство.
- В игре: `~` показывает FPS и счётчики; в консоли браузера `__G.player.level = 15; __G.player.recalc()` — быстрый тест высоких уровней.
