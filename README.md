# ЗАВОД · Ночная смена

Пошаговый рогалик для телефона (работает и на компьютере). Ты — дежурный инженер
заброшенного завода. Спустись на 10 цехов вниз и отключи Директора — машину,
которая управляет станками.

## Как запустить

Открой `index.html` в браузере. Это один файл без зависимостей: графика —
процедурный пиксель-арт в коде, звук — синтез Web Audio. Из сети подгружаются
только шрифты Google Fonts (без них игра тоже работает).

## Что есть в игре

- Процедурные уровни: 10 цехов с комнатами, коридорами и туманом войны.
- 7 видов врагов и босс: крысы, дроны, мазутники (делятся при гибели),
  сварщики и турели (стреляют издалека, турель предупреждает миганием),
  охранники, Директор (вызывает подмогу, впадает в ярость на половине здоровья).
- Конвейерные ленты двигают всех, кто на них стоит.
- Взрывные бочки: удар поджигает, через 2 хода взрыв 3×3 с цепной реакцией.
- Торговые автоматы: болты меняются на аптечки, гранаты, ЭМИ и сгущёнку.
- Разряды (уровни): при повышении выбираешь 1 из 3 навыков.
- Автосохранение забега, рекорды, настройки звука и тряски.

## Управление

- Телефон: свайп или тап по соседней клетке — шаг; тап по дальней клетке — идти туда;
  тап по себе — ждать (на лифте — спуститься). Кнопки снизу — предметы.
- Клавиатура: стрелки / WASD, диагонали Q E Z C, пробел — ждать, 1–4 — предметы,
  Enter — лифт, Esc — пауза, `~` — отладочный оверлей.

## Файлы

- `game.html` — исходник игры (фрагмент страницы, в таком виде публикуется как Artifact).
- `index.html` — самостоятельная страница, собирается командой `./build.sh`.
- Баланс (здоровье, урон, шансы) — в объекте `CONFIG` и таблицах `MONS`, `WEAPONS`, `ARMORS`, `PERKS`.
