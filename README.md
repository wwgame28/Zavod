# АмурМания — витрина-«вешалка»

Концепт сайта для [amurmania.ru](https://amurmania.ru) в стиле интерактивной витрины магазина одежды:
вещи висят на штанге, при наведении покачиваются и увеличиваются, клик открывает детальный просмотр.

Открыть: `index.html` в браузере (без сборки и зависимостей).

## Что внутри
- **Вешалка (hero)** — вещи на SVG-плечиках, лёгкое покачивание, «swing» при наведении, затемнение соседей, подпись с ценой.
- **Детальный просмотр** — стрелки ←/→ (клавиатура и свайп), смена цвета (кружки и мини-вешалка справа), размеры S-M / M-L / L-XL, «В корзину».
- **Бегущая строка** внизу в фирменном красном.
- **Каталог** с фильтрами, блоки «цифры», преимущества, «О нас», бренды, услуги, контакты — тексты с amurmania.ru.
- Корзина хранится локально в браузере (localStorage); оформление — по телефону.

## Фото
- Каталог и детальный просмотр футболок показывают **реальные фото с amurmania.ru** (13 моделей, 2–4 фото
  каждая; ссылки в поле `photos` массива `PRODUCTS` в `app.js`). Фото грузятся с сервера amurmania.ru напрямую.
- Если фото не загрузилось, вместо него автоматически показывается SVG-рисунок.
- На вешалке (hero) пока SVG-рисунки: для эффекта «вещь висит» нужны фото вещей на плечиках без фона
  (PNG/WebP с прозрачностью) — их можно подставить вместо `garmentSvg` в `.rack__item`.
- У ZIP-худи фото на сайте не найдено — показаны рисунки в реальных цветах из каталога.

## Инструменты Claude Code для дизайна и моушена
В `.mcp.json` подключены MCP-серверы (включаются автоматически через `.claude/settings.json`):
- **playwright** — открывает сайт в браузере: скриншоты, наведение/клики, проверка анимаций и адаптива
  (`scripts/playwright-mcp.sh`; в облаке использует предустановленный Chromium).
- **context7** — свежая документация библиотек анимации и вёрстки (GSAP, Motion, Lenis и др.).
- **magicui** — каталог анимированных UI-компонентов Magic UI (исходники на React/Tailwind — как референс эффектов).

В облачном окружении для context7 и magicui нужно разрешить домены `context7.com` и `magicui.design`
(Network access → Allowed domains в настройках окружения).
