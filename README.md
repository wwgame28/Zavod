# АмурМания — витрина-«вешалка»

Концепт сайта для [amurmania.ru](https://amurmania.ru) в стиле интерактивной витрины магазина одежды:
вещи висят на штанге, при наведении покачиваются и увеличиваются, клик открывает детальный просмотр.

Открыть: `index.html` в браузере (без сборки и зависимостей).

## Что внутри
- **Вешалка (hero)** — вещи на SVG-плечиках, лёгкое покачивание, «swing» при наведении, затемнение соседей, подпись с ценой.
- **Детальный просмотр** — стрелки ←/→ (клавиатура и свайп), смена цвета (кружки и мини-вешалка справа), размеры S-M / M-L / L-XL, «В корзину».
- **Бегущая строка** внизу в фирменном красном.
- **Каталог** с фильтрами, блоки «цифры», преимущества, «О нас», бренды, услуги, контакты — тексты с amurmania.ru.
- Корзина хранится локально в браузере (localStorage); оформление — по телефону.

## Как заменить картинки на реальные фото
Одежда сейчас нарисована в SVG (`garmentSvg` в `app.js`). Для продакшена сфотографируйте вещи на
вешалке на однотонном фоне, удалите фон (PNG/WebP с прозрачностью) и подставьте `<img>` вместо SVG —
анимации работают с любым содержимым `.rack__item`.

Цены и названия — с сайта. Цвета футболок и принты — иллюстративные, поправьте массив `PRODUCTS` в `app.js`.
